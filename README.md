# Keymap configs for Lily58

View and edit online [here](https://nickcoutsos.github.io/keymap-editor/)
- Github action autogenerates config files

## Flashing a new version

1. Make changes using the editor above or push a new commit
2. Go to the repo's [Actions tab](https://github.com/abhilash-nandkumar/zmk-config/actions) and download the latest firmware (it may take time to be generated).
3. Connect the master half(left) with a cable and press the reset button twice. It will mount the storage `NICENANO`.
4. Drag and drop the left `.uf2` file.
5. Repeat for the right half.
